# My First Node.js Project

## About
This is my first project using Node.js and npm.
I created a simple web server using Node.js.

## Technologies Used
- Node.js
- npm
- JavaScript
- Visual Studio Code

## Installation Steps

1. Download Node.js LTS.
2. Install Node.js on Windows.
3. Verify Node.js using node -v.
4. Verify npm using npm -v.
5. Create a project folder.
6. Run npm init -y.
7. Create server.js.
8. Run the project using node server.js.
9. Open localhost:3000 in the browser.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run npm start.
4. Open http://localhost:3000.

## Output

The browser displays a welcome
message from the Node.js server.
